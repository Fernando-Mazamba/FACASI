2. O que recebe

  • sgi-facasi-v1.1.0-sistema-parte1de3.zip, …parte2de3.zip, …parte3de3.zip — cada parte tem menos de 30 MB e contém a pasta raiz sgi/. Extraia todas as partes para o mesmo sítio; os ficheiros juntam-se dentro de sgi/.
  • CODIGO-INSTALACAO.txt — entregue em separado. O pacote contém apenas o hash do código.
  • SHA256SUMS.txt — para conferir os ficheiros descarregados (opcional).
O assistente confirma que as 3 partes foram extraídas: cada ficheiro é verificado contra o manifesto PACOTE.json (SHA-256). Se faltar uma parte, a instalação não avança e indica qual falta.

3. Instalação no cPanel (passo a passo, sem Terminal)

  1. Criar a base de dados. cPanel → Bases de dados MySQL → «Criar nova base de dados» (ex.: conta_sgi).
  2. Criar o utilizador da base. Na mesma página → «Adicionar novo utilizador» com uma palavra-passe forte (use o gerador). Anote-a.
  3. Dar privilégios. «Adicionar utilizador à base de dados» → escolha o utilizador e a base → marque TODOS OS PRIVILÉGIOS → «Fazer alterações».
  4. Escolher a versão do PHP. cPanel → Selecionar versão do PHP → 8.2 ou 8.3 → separador Extensões: confirme pdo_mysql, mbstring, fileinfo, zip, gd, curl, dom, openssl.
  5. Enviar o pacote. cPanel → Gestor de ficheiros → abra a pasta do domínio/subdomínio (ex.: public_html ou a pasta do subdomínio textesgi) → Carregar → envie as 3 partes ZIP.
  6. Extrair. Selecione cada ZIP → Extrair → confirme a pasta atual. Repita para as 3 partes. Deve ficar uma pasta sgi/. Pode apagar os ZIP depois.
  7. (Recomendado) Pasta de dados fora da pasta pública. No Gestor de ficheiros, ao nível da pasta home (acima de public_html), crie sgi-dados. O assistente sugere este caminho automaticamente quando é possível.
  8. Abrir o assistente. No navegador: https://SEU-DOMINIO/sgi/instalar/.
  9. Preencher. Código de instalação (do ficheiro separado) · dados da base (servidor localhost, nome e utilizador com o prefixo da conta) · pasta de dados · administrador da plataforma · primeira organização (FACASI) e o seu administrador. Para a FACASI, deixe marcada a opção de importar os 165 documentos originais.
  10. Instalar. No fim aparece «Instalação concluída». A partir daí o assistente fica bloqueado.
  11. Primeiros passos. Entre como administrador da plataforma → Cópias de segurança → «Criar cópia de segurança agora». Depois entre como administrador da FACASI e crie os utilizadores.
Não existe nenhuma palavra-passe fixa ou pública. O primeiro administrador é criado no assistente, protegido pelo código de instalação (5 tentativas falhadas bloqueiam o assistente durante 15 minutos).

4. Contas criadas na instalação

ContaO que fazO que não faz
Administrador da plataformaOrganizações, biblioteca de modelos, cópias de segurança, atualização, correio SMTP, push, estado do sistema.Não abre documentos nem registos das organizações (a API recusa: plataforma_sem_acesso).

5. Tarefas diárias (opcional)

Lembretes do calendário, avisos de ações atrasadas e de verificações de equipamentos, limpeza de dados temporários. Sem configuração, correm uma vez por dia após o primeiro acesso. Para horário fixo: cPanel → Tarefas Cron → «Uma vez por dia» → comando:

php -q /home/CONTA/public_html/sgi/cron.php

Também pode executá-las em Plataforma → Estado do sistema → Executar tarefas diárias.

6. Limites de envio

O pacote inclui sgi/.user.ini (upload 20 MB, memória 256 MB, 300 s). Em alguns servidores estes valores levam até 5 minutos a aplicar ou são definidos em cPanel → Selecionar versão do PHP → Opções. As fotografias são comprimidas no telemóvel (máx. 1600 px) antes de serem enviadas.

7. Ambiente local de desenvolvimento e testes

Para programadores (não é necessário em produção):

# MariaDB/MySQL local
sudo service mariadb start
mysql -uroot -e "CREATE DATABASE sgi_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'sgi'@'localhost' IDENTIFIED BY 'sgi_dev_pw'; GRANT ALL ON sgi_dev.* TO 'sgi'@'localhost';"

# biblioteca de modelos da FACASI a partir deste repositório
php sistema/tools/sync-modelos.php

# código de instalação local (o hash vai para sgi/instalar/codigo.hash)
php sistema/tools/gen-install-code.php

# servidor embutido do PHP, com a mesma subpasta /sgi/ da produção
php -S 127.0.0.1:8080 -t sistema sistema/sgi/dev-router.php
# abrir http://127.0.0.1:8080/sgi/instalar/

O dev-router.php reproduz as proteções do .htaccess (o servidor embutido não lê .htaccess). Bateria completa de testes (php -S e Apache): bash sistema/tests/run-all.sh — ver Relatório de testes.

8. Problemas comuns

MensagemSolução
«Não foi possível ligar à base de dados»Confirme o nome completo com prefixo (conta_sgi), o utilizador e que lhe deu «Todos os privilégios».
«Falta extrair a(s) parte(s) …»Extraia as partes indicadas para a mesma pasta.
«EM FALTA — ative em cPanel…»Ative a extensão indicada em Selecionar versão do PHP → Extensões.
A aplicação não aparece para instalar no telemóvelConfirme que o site abre com https:// (cadeado) e não com http://.
