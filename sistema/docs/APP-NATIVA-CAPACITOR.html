Aplicação nativa Android e iOS (Capacitor)

Opcional — a aplicação instalável pelo navegador (PWA) já funciona sem lojas

← Documentação

1. Precisa mesmo da versão de loja?

A PWA instala-se a partir do navegador em Android e iPhone (ver Guia passo a passo), trabalha sem ligação, usa câmara, QR e localização, e atualiza-se sozinha. A versão de loja só é necessária se a empresa quiser distribuir pela Google Play / App Store ou gerir os telemóveis com MDM.

2. O que foi entregue

  • sgi-facasi-v1.1.0-app-capacitor.zip com a pasta capacitor/: projeto Capacitor 8.5.3 com as plataformas android/ e ios/ já criadas.
  • A aplicação abre o SGI do servidor (server.url, por omissão https://facasi.continentalconsulting.org/sgi/) e usa a mesma API e base de dados. Dentro da aplicação, o SGI usa tokens por dispositivo (revogáveis em Perfil → Dispositivos).
  • Permissões já declaradas: câmara (fotografias e QR), localização (opcional), Internet. iOS: textos de pedido de permissão em português e domínio do SGI em WKAppBoundDomains (necessário para o funcionamento sem ligação no iPhone).

O que NÃO foi possível gerar neste ambiente

  • APK de teste e AAB para a Play Store: não gerados. O ambiente de desenvolvimento não tem acesso ao repositório da Google (dl.google.com devolveu 403), de onde vêm o Android SDK e o plugin Gradle. A tentativa de compilação (./gradlew assembleDebug) falhou por esse motivo, não por erro no projeto.
  • iOS: não gerado. Requer um Mac com Xcode.
  • Testes num telemóvel real (Android ou iPhone) não foram feitos. Os testes automáticos usam Chromium com emulação móvel (Pixel 7, 390 px).

3. Gerar o APK de teste (Windows, Mac ou Linux) — passo a passo

  1. Instalar o Node.js (versão 22 LTS) de nodejs.org e o Android Studio (developer.android.com/studio). Abra o Android Studio uma vez e aceite a instalação do SDK.
  2. Extrair sgi-facasi-v1.1.0-app-capacitor.zip numa pasta (ex.: Documentos\sgi-app).
  3. Abrir um terminal nessa pasta (Windows: na pasta, escreva cmd na barra de endereço e Enter).
  4. Instalar as dependências: npm install
  5. Indicar o endereço do seu SGI (se não for o de omissão): npm run configurar -- https://SEU-DOMINIO/sgi/
  6. Sincronizar: npx cap sync
  7. Abrir no Android Studio: npx cap open android. Espere que termine o «Gradle sync» (barra inferior).
  8. APK de teste: menu Build → Build App Bundle(s) / APK(s) → Build APK(s). No fim, «locate» mostra app-debug.apk. Copie para o telemóvel e instale (é preciso permitir «instalar apps de origem desconhecida»).

4. Publicar na Google Play (AAB)

  1. Conta de programador Google Play (taxa única, paga pela empresa): play.google.com/console. Exige verificação de identidade da organização.
  2. Escolha o identificador definitivo da aplicação em capacitor.config.json → appId (por omissão ao.facasi.sgi; não pode mudar depois de publicado). Depois npx cap sync.
  3. Android Studio → Build → Generate Signed Bundle / APK → Android App Bundle → «Create new…» keystore. Guarde o ficheiro .jks e as palavras-passe em local seguro: sem eles não poderá publicar atualizações.
  4. Na Play Console: criar aplicação → ficha da loja (descrição, ícone 512×512, capturas de ecrã) → política de privacidade (URL) → classificação de conteúdo → «Segurança dos dados» (indique: fotografias e localização opcionais, guardadas no servidor da empresa) → carregar o .aab num teste interno → depois produção.

5. iPhone / iPad (App Store)

  1. Precisa de um Mac com Xcode e de uma conta Apple Developer Program (anual, em nome da empresa — D-U-N-S).
  2. No Mac: npm install → npx cap sync ios → npx cap open ios.
  3. No Xcode: Signing & Capabilities → escolher a equipa; confirmar o Bundle Identifier; se mudou o endereço do SGI, atualize WKAppBoundDomains em Info.plist.
  4. Product → Archive → Distribute App → App Store Connect → TestFlight para testes → submissão para revisão.
